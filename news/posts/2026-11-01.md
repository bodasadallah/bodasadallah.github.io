<h2 class="dn-section">Research and techniques</h2>

<div class="dn-item">
<h3><a href="https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/" target="_blank" rel="noopener">How We Took Over ChatGPT Accounts</a></h3>
<div class="dn-meta">Simon Willison · Oct 31</div>
<p>Parameter Labs describe an attack chain that let them take over ChatGPT accounts with a single link. Untrusted code in sandboxed HTML preview frames could use the MathLive virtual keyboard's postMessage handler to inject an unsandboxed iframe into the parent page and get around OpenAI's content security policy. It is a detailed case study in how LLM artifact sandboxes can fail.</p>
</div>

<div class="dn-item">
<h3><a href="https://simonwillison.net/2026/Oct/30/nesformer/" target="_blank" rel="noopener">dbreunig/nesformer</a></h3>
<div class="dn-meta">Simon Willison · Oct 30</div>
<p>Drew Breunig built nesformer, which bakes a working NES 6502 CPU emulator into the weights of Qwen3.5-4B, so the model can run Super Mario Bros very slowly. He built it largely with Opus 5.5, which found and used a 15-year-old CPU conformance test suite.</p>
</div>
